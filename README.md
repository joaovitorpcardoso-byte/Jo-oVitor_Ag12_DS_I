# Meus sites favoritos

Página web em HTML com 5 sites favoritos. Cada site tem o nome (acima), a imagem e o link (abaixo).

## Arquivos
- `index.html` - página (código comentado)
- `youtube.png`, `github.png`, `wikipedia.png`, `spotify.png`, `stackoverflow.png` - imagens, na mesma pasta do HTML
- `captura_codigo.png` - captura do código com comentários
- `captura_execucao.png` - captura da página no navegador

## Como abrir
Dê dois cliques em `index.html` ou abra-o pelo navegador.
